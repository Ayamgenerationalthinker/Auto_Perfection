# Auto Perfection Centre — Website

A high-performance, modern automotive website concept built for **Auto Perfection Centre**, located at Star Oil, La-Bawaleshi Road, Accra, Ghana.

This website was designed as a production-quality proposal concept by **AGT TECH** to present to the business owner, delivering an authoritative digital presence that turns Google searches into direct phone calls, WhatsApp consultations, and workshop visits.

## ⚡ Tech Stack & Highlights

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 (Pure modern dark automotive design system)
- **Icons**: Lucide React
- **SEO & Structured Data**:
  - Full OpenGraph & Twitter metadata
  - Verified JSON-LD `AutoRepair` / `LocalBusiness` schema with Google review ratings and service catalog
- **Mobile First**: Fixed 1-tap WhatsApp and Call action bar for mobile viewports, responsive navigation drawer, and zero horizontal scroll.
